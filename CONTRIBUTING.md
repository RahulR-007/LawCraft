# Contributing Guidelines

Thank you for your interest in contributing to LawCraft AI.

## Workflow

1. Fork the repository and create a feature branch (`git checkout -b feature/amazing-feature`).
2. Follow TypeScript and ESLint standards (`npm run lint`).
3. Ensure all unit tests pass (`npm run test:run`).
4. Commit changes with clear, professional messages.
5. Open a Pull Request for review.

## Code Standards
- Use TypeScript interfaces for component props and state.
- Keep components focused and reusable.
- Follow the Chakra UI design system tokens defined in `src/theme.new.ts`.
